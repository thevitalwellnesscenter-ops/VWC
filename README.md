# VWC — VitalOne EHR Concept

Product concept for **VitalOne**, a hybrid cloud EHR for primary care that combines:

- **athenaOne** (athenahealth): clinical charting (athenaClinicals), revenue cycle management (athenaCollector), and patient engagement (athenaCommunicator)
- **Opti** family: OptiMantra-style flexible scheduling, packages/memberships and hybrid cash+insurance billing; EmOpti-style clinic throughput and live queue workflows
